
# 📝 To-Do List Application

A full-stack To-Do List application built with **Spring Boot (Java)** as the backend, **React.js** as the frontend, and **MySQL** as the relational database. This application allows users to create, update, delete, and view their to-do tasks in a clean and responsive UI.

---

## 🧱 Tech Stack

### Backend
- **Spring Boot**
- **Spring Data JPA**
- **MySQL**
- **Maven**
- **RESTful APIs**

### Frontend
- **React.js**
- **Axios**
- **Bootstrap / Tailwind CSS** (choose one)
- **React Hooks**

---

## ⚙️ Features

- Create new to-do tasks
- View all tasks
- Update task status or content
- Delete tasks
- Persist tasks using MySQL
- Fully responsive user interface
